# Enterprise engineering standards

The organization's coding standards, packaged as agent skills. They're owned by the Platform, Security and Backend teams, and distributed to developers through Port: each developer's machine syncs the skills they're entitled to at the start of every session, and the Port PR review workflow re-checks every pull request against the same standards.

| Skill | Owner |
| --- | --- |
| [`secure-coding-standard`](skills/secure-coding-standard/SKILL.md) | Security Team |
| [`data-classification-handling`](skills/data-classification-handling/SKILL.md) | Security Team |
| [`api-service-standards`](skills/api-service-standards/SKILL.md) | Backend Team |
| [`platform-golden-paths`](skills/platform-golden-paths/SKILL.md) | Platform Team |

Changes go through a pull request reviewed by the owning team. Don't install these by hand; Port keeps them in sync.
